# tutor-kb-loop — 知识库 × 导师视角 互补循环优化

> **一句话定位**：导师视角定义领域「应该有什么」，知识库提供「有什么」；差距即文献缺口，补齐后反哺视角，视角锐化后再找新差距——两者互相喂养、螺旋收敛。

编排型 WorkBuddy skill：在「导师画像（脑）」与「知识库（体）」之间跑互补循环，把目标对发现、缺口审查、下载、转换、消化、反馈写回串成一条可追踪、可收敛的闭环。

**环境无关**：主文档零硬编码（无盘符、无用户名、无领域名）。环境特定的东西（路径、包状态、领域防错项）全部装进**随库走的环境档案**里——换环境只换档案，方法论一个字不用动。

## 核心理念

- **导师视角 = 脑**：导师画像定义领域判断标准与理想态（该有什么基因/路线/数据/缺口）。
- **知识库 = 体**：提供实证事实与数据（哪些发现验证过、哪些带置信度标注）。
- **互为检验**：视角缺事实支撑会飘，事实缺视角组织会散。
- **循环**：视角定义理想态 → 缺口审查找差距 → 补文献 → 新事实反馈写回画像 → 视角锐化 → 找新差距 → 螺旋收敛。

## 完整流程（Step 0 + 5 步循环）

```
Step 0 目标对发现  → 确定「导师组 ↔ 知识库」这一轮跑哪一对，支持多库切换
                     双通道扫描导师包（库内 + 向上扩展搜库外），识别布局模式与权限
Step 1 缺口审查    → 五路来源合并 → 输出《文献缺口台账》（GapNNN + P0/P1/P2 + 状态机）
Step 2 下载文献    → raw/pdfs_original/（付费墙尝试替代通道，不靠模型记忆）
Step 3 转 Markdown → raw/pdfs_md/（优先 anydoc，回退 markitdown；OCR 失败标 blocked）
Step 4 消化进知识库 → wiki/sources/（置信度标注 EXTRACTED/INFERRED/AMBIGUOUS/UNVERIFIED）
Step 5 反馈写回画像 → 个人事实→个人画像；领域判断→联合画像 board.md
                     只补带来源的事实，不改思维模型本体
                     收敛判定：连续 2 轮无新增 P0/P1 + P2 全部显式处置 + 导师核心文献覆盖率达标
```

### 五路缺口来源

| # | 来源 | 说明 |
|:--|:--|:--|
| 1 | 导师画像理想态 | 核心心智模型 / 决策启发式 / 时间线 / 价值观与反模式 / 智识谱系 / 诚实边界 |
| 2 | 库内「待补」标注 | `[待创建`、`confidence: AMBIGUOUS/UNVERIFIED`、`reviews/` 的 pending 项 |
| 3 | 已知最大缺口 | 上一轮台账遗留项 + 最近轮次日志 |
| 4 | 用户当前问题 | 本次调用想解决什么 |
| 5 | **导师核心文献覆盖率** | 弥补「循环只补边界、不补文献存量」的短板 |

第五路的产出是文献增量的主要来源，采用**三级回退**取待核清单（多环境实测一手 PDF 常缺失）：

- **L1** `references/sources/articles/*.pdf`（最理想）
- **L2** 递归 `references/**/*.pdf`
- **L3** 无 PDF 时，从调研底稿的「代表性论文」表格抽取代表论文清单

> **坑**：表格里的年份常不带括号，用 `\((19|20)\d{2}\)` 类正则会全军覆没。必须先定位 `## 代表性论文` 章节再按实际列序解析，正则只作兜底。
> L1–L3 全空 → 分「薄包底稿缺失」（登记 P1 画像侧缺口）与「确无清单」（标不可核算）两种，都不阻塞循环。

## 台账编号与字段

编号 **`GapNNN`** = Gap（文献缺口条目）+ 三位序号，如 `Gap001`。

- **三位补零**：不补零则 `Gap10` 会字符串排序排到 `Gap2` 前面，台账破百就乱
- **全局递增、关闭后不回收号**：历史轮次日志引用过，不能让 ID 改指别的东西
- **按发现顺序续号**，不按优先级重排（ID 只表示发现先后，不表示重要性）

每条含：文献标识 | 归属导师方向 | 为什么需要 | 来源可追溯性（A 检索到原文 / B 库内推断缺 / C 仅凭模型记忆）| 优先级 | 状态 | **子项完成度 x/y**。

**批量条目**（第五路产出，一条装多篇）：合成一条而非逐篇登记，因为这批文献**同源同质**（根因只有一个：导师核心文献存量未建）+ **同批动作**（批量下载→转换→消化）。逐篇登记会让 P0 计数虚高、顶死收敛门槛，还会把结构性存量缺口伪装成 N 个离散缺口。代价是状态机只能整体推进，故必须带 **「子项完成度 x/y」**（满格才允许置 `closed`）。

状态机：`open → downloaded → converted → ingested → fedback → closed`，分支 `blocked`（付费墙/OCR）、`declined`。

## 布局模式（Step 0 自动识别）

| 模式 | 特征 | 注意事项 |
|:--|:--|:--|
| **库内** | `<库>/tutor/*-perspective/` | 最常见，状态区与画像同处，写回方便 |
| **库外** | 导师包独立于库（多库共享一组导师时常见） | `<画像根>` 常**只读**（共享盘/他人维护），写回走 `pending` 分支 |
| **混合** | 部分在库内、部分在库外 | 两处都扫、去重 |
| **无导师包** | 库里没有导师画像 | 借用方向最接近的单导师，或先用 nuwa-skill 蒸馏 |

扫描策略：**只认包名特征（`*-perspective`），不认目录名**。以 `<库>` 为起点向上 1~2 级作搜索根、向下 1~3 层广度搜——因为写死「同级 `tutor/`」这类规则，本质上是在照抄某一个环境的长相，遇到 `tutors/` 或 `Mytutor/` 就会漏检。无权限目录跳过并标注，不中断扫描。

导师包判定三态：**完成包**（有 `SKILL.md` 且底稿完整）/ **薄包**（有 `SKILL.md` 但底稿无代表论文清单且无 PDF）/ **骨架包**（无 `SKILL.md`）。薄包最危险——会被误判为完成包，导致第五路静默空转。

## 安装

```bash
# 复制到 WorkBuddy 用户级技能目录
cp -r tutor-kb-loop ~/.workbuddy/skills/
```

依赖（可回退，缺失不阻塞核心流程）：

| 依赖 | 用途 | 回退方案 |
|------|------|---------|
| `llm-wiki` | 消化（ingest/batch-ingest）、知识库定位 | 按 wiki schema 手动消化 |
| 文献检索/下载（paper-search MCP / WebSearch） | 下载全文 | 用户手动提供 PDF |
| anydoc / markdown-converter | PDF→Markdown | Read 直接读取 |
| `nuwa-skill`（可选） | 建库前置：新领域蒸馏 Top5 导师画像 | 跳过蒸馏 |

## 使用

在对话中说（手动触发为主，不配置定时任务）：

| 你说 | 它做 |
|------|------|
| 「跑一轮互补循环」 | **loop**：目标对→缺口审查→台账→下载/转换/消化→反馈写回→收敛判定→轮次登记 |
| 「有哪几对可用」/「用哪个知识库」 | **pairs**：只读扫描，列出目标对、布局模式、包状态、环境档案状态 |
| 「缺口审查」/「知识库还缺什么文献」 | **gap-audit**：五路来源聚合，输出缺口台账 |
| 「下载文献 X」 | **fetch**：检索→验证→落位→转换→更新台账 |
| 「反馈写回画像」 | **feedback**：归属路由写回 + 反馈日志登记 |
| 「循环状态」/「收敛了吗」 | **status**：只读台账+轮次日志，输出收敛判定 |

## 环境档案（换环境只换这里）

首次在某环境跑 `pairs` 会提示补建 `<库>/tutor/loop/environment.md`，承载：目标对清单与布局模式、导师包状态、第五路基线、**领域专属防错清单**、历史轮次索引。

之后每轮循环先读它，省掉重复摸底。参见 `templates/environment-template.md` 与 `examples/hpmaize-environment.md`（完整填法样例，含两轮真实执行记录）。

## 文件结构

```
tutor-kb-loop/
├── SKILL.md                        # 主文件（Step 0 + 五路来源 + 6 个工作流 + 状态机 + 通用防错清单）
├── templates/
│   ├── ledger-template.md          # 缺口台账模板（GapNNN、子项完成度、单篇/批量样例）
│   ├── board-template.md           # 联合画像模板（领域共识/技术路线×方法矩阵/交叉视角/工作清单）
│   ├── log-template.md             # 轮次记录 + 反馈日志模板
│   └── environment-template.md     # 环境档案模板（随库走，承载环境特定数据）
└── examples/
    └── hpmaize-environment.md      # 环境档案完整填法样例 + R01/R02 实战记录
```

运行时在知识库内（懒初始化，首次运行自动补建）：

```
<知识库>/tutor/
├── board.md                   # 联合画像（领域级动态内容）
├── [person]-perspective/      # 导师画像包（只读数据源）
└── loop/
    ├── environment.md         # 环境档案（随库走）
    ├── ledger.md              # 缺口台账
    ├── log.md                 # 轮次记录（收敛判定依据）
    └── feedback-log.md        # 反馈日志
<知识库>/raw/pdfs_original/    # 文献原文
<知识库>/raw/pdfs_md/          # 文献转换 Markdown
```

## 设计要点

- **不重复造轮子**：消化走 llm-wiki、蒸馏走 nuwa-skill、转换走 anydoc，本 skill 只做编排与状态管理
- **环境无关**：主文档纯方法论，环境特定数据全部下沉到环境档案
- **可追溯**：台账每条带来源可追溯性（A / B / C，C 级默认降 P2）；写回画像带 `<!-- 来源: wiki/sources/<页> | confidence: EXTRACTED -->` 注释
- **收敛判定**：连续 2 轮无**新增** P0/P1 + P2 全部显式处置（closed/blocked/declined）+ **导师核心文献覆盖率达标**（每位完成包导师代表论文 ≥1 篇；可核算时 ≥30%）。受阻项（付费墙/OCR）不算未收敛
- **防错清单分两级**：**通用防错**（主文档，工具/流程类，跨领域有效）+ **领域防错**（环境档案，如「某论文已撤稿」这类随人员变动最易丢失的资产）
- **防写回冲突**：同一事实只落一处；个人事实只写个人画像，领域判断才写联合画像
- **画像永远只读**：`<画像根>` 不可写时，写回内容落 `feedback-log.md` 标 `pending`，不静默失败
- **思维模型本体保护**：模型名/一句话定义改动须强证据 + 人工确认
