## 条目

> **编号 `GapNNN`** = Gap（文献缺口条目）+ 三位序号，如 `Gap001`。三位补零（防止 `Gap10` 排到 `Gap2` 前面）；全局递增，关闭后不回收号。

### Gap001（单篇示例）
- **文献标识**：作者(年份) 《标题》 / DOI
- **归属导师方向**：领域整体 / 具体导师名
- **为什么需要**：补哪个锚点 / 哪个交叉视角 / 哪个工作清单项
- **来源可追溯性**：A=检索到原文 / B=库内推断缺 / C=仅凭模型记忆
- **优先级**：P0 / P1 / P2
- **状态**：open（或 downloaded / converted / ingested / fedback / closed / blocked(原因) / declined）
- **子项完成度**：`-`（单篇填 `-`；批量条目填 `x/y`，满格后才可置 closed）
- **备注**：（骨架包方向标「待蒸馏」；C 级默认降 P2）

- **优先级**：P0
